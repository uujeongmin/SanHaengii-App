# SanHaengii-App

**산행이(SanHaengii)** 프로젝트의 **모바일 앱(프론트엔드)** 레포지토리입니다.

React Native · Expo 기반 등산 안전 앱으로, 등산로 탐색, 실시간 지도·내비게이션, 생체데이터 기반 이상징후 감지, 스마트워치 연동 기능을 제공합니다.

## 조직 내 레포지토리 구성

| 레포지토리 | 역할 |
| --- | --- |
| **SanHaengii-App** (본 레포) | 모바일 앱 — React Native / Expo |
| [SanHaengii-backend](https://github.com/SanHaengii/SanHaengii-backend) | 백엔드 API — Flask / Supabase |
| [SanHaengii-Wear](https://github.com/SanHaengii/SanHaengii-Wear) | 스마트워치 앱 — Wear OS / Kotlin |

## 브랜치

- `main` — 통합 브랜치
- `feat/watch-integration` — 스마트워치 헬스 데이터 연동
